# Product Requirements Document

## Project Overview
**Name:** shopping_list_app
**Type:** web_application
**Created:** 2026-11-01T18:08:43.451628

## Description
Build a minimal shopping list app. User authentication (email/password). Create, check-off, and delete items. List all items for the logged-in user. (Type: web_app)

## Features
- authentication
- item_creation
- item_check_off
- item_deletion
- list_items

## User Stories
### User Authentication
As a user, I want to create an account and log in so that I can access personalized features.

**Acceptance Criteria:** User can register, login, logout, and reset password

## Business Logic
- User authentication
- CRUD operations on shopping items
